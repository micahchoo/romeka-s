# Media matrix baseline

One row per file in this directory, one column per part of Romeka. Each cell is what
the server answered for that file through the public API, the public site and the IIIF
manifest. A `**fail**` is a red cell.

Generated by the matrix test with `MEDIA_MATRIX_PRINT=1`:

```
MEDIA_MATRIX_PRINT=1 cargo test -p omeka-server --test media_matrix -- --nocapture
```
